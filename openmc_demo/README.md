# Paramak → DAGMC → OpenMC → OpenFOAM demo chain

A small, reproducible example that goes from a parametric tokamak CAD model to
neutron wall loading and then to a conjugate heat transfer calculation of the
first wall.  Everything is driven by scripts in this folder; the numbers below
come from the runs committed here.

## Contents

| path | what it does |
|---|---|
| `paramak_cad_demo.py`, `cad_output/` | builds two paramak assemblies (radial build tokamak, EU DEMO 2015), exports STEP/HTML and a contact sheet |
| `wall_loading.py`, `plot_results.py` | elliptical torus CSG model in OpenMC: 14.1 MeV source, wall current tally, TBR proxy, transmitted spectrum |
| `dshape/export_step.py` | D-shaped tokamak from a radial build (R0 = 6.2 m, a = 2 m, kappa 1.7, delta 0.55), exports one STEP per part in mm |
| `dshape/convert.py` | STEP to DAGMC `h5m` with material tags, mm to cm scaling (`cad_to_dagmc`) |
| `dshape/make_source.py` | rejection samples neutron birth sites inside the CAD plasma volume |
| `dshape/wall_loading_dagmc.py` | OpenMC run on the DAGMC model, same tallies as the CSG case |
| `dshape/plot_dshape.py` | cross section with source sites, spectrum comparison, ellipse vs D table |
| `dshape/openfoam/fw_conduction/` | steady conduction through the 3 cm tungsten wall, heat flux from the wall loading |
| `dshape/openfoam/fw_cht/` | conjugate heat transfer: tungsten wall + helium channel (`chtMultiRegionSimpleFoam`, k-epsilon) |
| `dshape/openfoam/plot_openfoam.py` | wall temperature profile, heat balance, thermal chain |
| `dshape/report.html` | self contained report (Chinese) of the whole chain |
| `dshape/energy_chain_animation.html` | 40 s animated explanation, from D-T fusion to net electricity |

## Running it

CAD and STEP export (python with `paramak` and `cadquery`):

```bash
python dshape/export_step.py          # -> dshape/step/*.step (mm)
python dshape/make_source.py          # -> dshape/source_sites.csv (cm)
```

CAD to DAGMC (`cadquery`, `cad_to_dagmc`, `cad-to-dagmc-mesher`):

```bash
micromamba create -n cad2dagmc -c conda-forge python=3.12 cadquery cad_to_dagmc
pip install cad-to-dagmc-mesher
micromamba run -n cad2dagmc python dshape/convert.py   # -> dshape/dshape.h5m
```

Neutronics (`openmc` built with DAGMC, plus a cross sections file):

```bash
export OPENMC_CROSS_SECTIONS=/path/to/cross_sections.xml
BATCHES=30 PARTICLES=100000 THREADS=10 python dshape/wall_loading_dagmc.py
```

Thermal (`OpenFOAM` 1912 in WSL/Linux).  OpenFOAM cannot handle paths with
spaces, so `run_case.sh` copies the case to `~/of_cases/` and copies the
results back:

```bash
bash dshape/openfoam/fw_conduction/run_case.sh
bash dshape/openfoam/fw_cht/run_case.sh
python dshape/openfoam/plot_openfoam.py
```

## Notes and gotchas

- The h5m mesh is not committed (22 MB, regenerated by `convert.py`); the STEP
  files are, so the conversion step can be repeated without paramak.
- the `h5m` file is unitless and OpenMC assumes centimetres, so the STEP parts
  (millimetres) are scaled by 0.1 during the conversion.
- the DAGMC model uses an implicit complement with material tag `vacuum`; OpenMC
  still needs a material with that name, and a material needs at least one
  nuclide, so the void is hydrogen at 1e-20 g/cm3.
- `openmc.DAGMCUniverse(..., auto_geom_ids=True)` avoids clashing with the CSG
  bounding box, which supplies the vacuum boundary.
- the wall loading is P/A: `0.8 * P_fusion / A_first_wall`, so it is almost
  independent of the plasma shape; triangularity mainly redistributes the
  poloidal flux.
- the gmsh meshing backend failed on the revolved spline surfaces, the
  `cad-to-dagmc-mesher` backend (tolerance 0.15 cm, angular 0.25) works.
- the OpenFOAM 1912 build packaged by apt has no tutorials and crashes with an
  `IOstream "sha1"` error when `functions` (sampling) objects are used, so the
  fields are parsed directly with python instead.
- the CFD heat transfer coefficient (2.8 kW/m2K) is below the Dittus-Boelter
  estimate (7.3 kW/m2K), i.e. the surface temperature is a conservative upper
  bound; a finer near-wall mesh or k-omega SST would lower it.
